# Secure Cloud Platform

Part of the 60-day Cloud + DevOps + Cloud Security engineering programme.

## Working principles

- Prefer reproducible, reviewable changes.
- Keep credentials, private keys, and Terraform state out of Git.
- Record compatibility assumptions and verification commands.
- Use small commits with clear intent.

## Initial structure

- `docs/` — design notes and operating procedures
- `architecture/` — diagrams and decisions
- `scripts/` — repeatable local automation
- `security/` — controls, findings, and remediation
- `tests/` — validation and exercises
